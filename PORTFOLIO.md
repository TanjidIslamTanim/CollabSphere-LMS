# CollabSphere project portfolio

This repository now includes a responsive, static case study at `portfolio/index.html`.

## Publish with GitHub Pages

1. Open **Settings → Pages** and select **GitHub Actions** as the build source.
2. Open **Actions → Deploy project portfolio → Run workflow** and select `main`.
3. Wait for the deployment to succeed. The expected address is https://tanjidislamtanim.github.io/CollabSphere-LMS/.

Only the `portfolio/` directory is published. The actual application or backend is not deployed.

The screenshots are original images copied from the existing docs/screenshots Git blobs.

Developed and tested locally with XAMPP. This website showcases the project; it is not a live PHP application.
